# CivicVoice prototype

This is an independent, browser-only prototype built from the supplied specification. The linked repository was empty. Fictional seed reports are provided. Run a local static server, for example `npx serve .`, and open its URL. Data is stored in this browser's localStorage; clearing browser data removes it. No data is sent to officials or shared across devices.

## Implemented
Responsive issue feed, search, category and urgency filters, local issue creation, local discussion and one support click per issue per browser, informational representative, support and voting screens. The map is decorative. Nothing in the prototype establishes identity or prevents manipulation.

## Release status
This is not the specified MVP or suitable for real civic use. It has no authentication, server, database, RLS, evidence uploads, representative verification, immutable audit history, moderation, appeals, recognition, real campaign information, blockchain contract, wallet integration, transaction verification, operational monitoring, or deployed test environment. The local support restriction is not an anti-abuse control. A manifest is provided but offline caching and installability have not been verified. Do not enter sensitive information.

The requested final MVP requires a configured Supabase project, properly reviewed schema and authorization, an actual Sepolia deployment and funded deployer, operational/legal review, and a deployed test environment in which all acceptance criteria can be verified. None of those are represented as complete here.
